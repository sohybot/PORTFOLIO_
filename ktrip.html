01 · Background

기획 배경 &
서비스 핵심 가치

K-미디어의 글로벌 확산으로 방한 수요는 급증했지만, 외국인 관광객은 여전히 언어 장벽과 정보 탐색 비용으로 불편을 겪습니다. 단순 정보 제공이 아닌 취향 기반 맞춤 가이드가 필요했습니다.

📺

K-미디어 글로벌 확산

K-POP·드라마·예능·영화 등 한류 콘텐츠가 실제 방한 관광 수요로 전환되는 중

🧳

자유여행(FIT) 증가

패키지 여행 대신 개별 자유여행객이 늘며 맞춤형 정보 수요 급증

🚧

언어 장벽 & 정보 탐색 비용

한국 메뉴판·로컬 정보 접근의 어려움으로 여행 경험이 제한됨

💡

콘텐츠 취향 기반 가이드 부재

단순 관광지 나열이 아닌 K-콘텐츠 스토리와 연결된 여행 설계 필요

🎬 콘텐츠 중심 여행 경험

장소가 아닌 스토리와 취향 중심으로 여행을 설계합니다. K-콘텐츠 촬영지·맛집·관광지 데이터를 RAG로 연결합니다.

🔤 언어·문화 장벽 최소화

OCR + LLM 기반 메뉴판 분석으로 단순 번역을 넘어 재료·맛·맵기 등 의미 정보를 자동 생성합니다.

📸 여행 데이터 기반 선순환 구조

여행 로그 자동 기록 및 SNS 포스터 생성으로 사용자 데이터를 서비스 고도화에 활용합니다.

03 · Technical Challenges

기술 챌린지 &
해결 전략

2가지 핵심 기술 문제를 직접 정의하고, 좌표 기반 알고리즘과 JSON 구조화로 해결하여 OCR 인식률과 RAG 추천 정확도를 동시에 끌어올렸습니다.

CHALLENGE 01

OCR 자간 인식 문제

메뉴판 디자인 특성상 OCR이 "우 동", "김 치"처럼 단어를 분리 인식하여 번역 품질과 메뉴 인식 정확도가 저하되었습니다.

해결 전략

텍스트의 Y좌표 근접도를 활용해 같은 행의 글자를 병합(Y좌표 근접도 병합). 공간 좌표 정보를 LLM 프롬프트에 주입하여 의미 단위로 재구성했습니다.

의미 단위 재구성으로 인식률 개선
CHALLENGE 02

RAG 컨텍스트 구조화

초기에 단순 텍스트로 장소 정보를 전달했더니 LLM이 위치 정보나 콘텐츠 연관성을 정확히 파악하지 못해 추천 정확도가 하락했습니다.

해결 전략

장소명·관련 콘텐츠·좌표·특징을 Key-Value 기반의 구조화된 JSON 컨텍스트로 변환하여 LLM이 정확한 정보 기반으로 동선을 설계하도록 개선했습니다.

박소현
AI PRODUCT PLANNER

K-콘텐츠를 사랑하는 외국인 관광객의 불편을 해결하고자 KTrip을 기획했습니다. 단순 번역 앱이 아닌, 콘텐츠 취향을 이해하고 언어 장벽을 기술로 허무는 AI 여행 가이드를 설계했습니다. OCR 자간 문제를 좌표 알고리즘으로 해결하고, RAG 컨텍스트를 JSON 구조화로 개선하는 과정에서 기술과 기획의 연결 지점을 직접 경험했습니다.

AI Product Planning RAG 파이프라인 UX Flow 설계 OCR + LLM Azure OpenAI TravelTech 외국인 UX IA 설계
🎬

K-콘텐츠 취향을 여행 경로로 전환

드라마 촬영지·아이돌 활동지 등 콘텐츠 스토리를 RAG 파이프라인으로 연결해 "덕질 여행"을 체계적으로 설계할 수 있는 서비스를 기획했습니다.

기술 문제를 기획으로 정의하고 해결

OCR 자간 인식 오류를 좌표 알고리즘으로, RAG 추천 정확도 문제를 JSON 구조화로 해결하는 과정을 기획 단계에서 먼저 정의하고 개발팀과 협력했습니다.

⚖️

비용·속도·품질의 트레이드오프 설계

GPT-4 vs GPT-4o-mini 비교 프레임을 직접 설계하고, 비용 효율과 서비스 품질의 균형점을 찾아 GPT-4o-mini를 메인 모델로 선정했습니다.
